## 站点使用日志

- 账号卡片「更多」和「日志统计」增加「使用日志」，使用保存的账号 Key 查询 `/api/log/token`，兼容查询参数与 Bearer 认证。
- 展示日志时间、模型、令牌、输入与输出 Token、原始额度、耗时、流式标记和记录详情；支持手动刷新、搜索、类型筛选及每页 50 条的本地分页。
- 汇总仅覆盖站点返回的最近消费记录，不假定美元换算比例。上游日志时间仅转为 UTC+8，不应用宿主时差。
- 复用账号的直连或代理选择，返回实际节点；查询不会改动账号或任务，不保存站点日志。接口不支持、鉴权失败、限流、格式错误和超时明确提示。
- 当前账号 Key 的上游反射内容会隐藏；错误不会回传带 Key 的 URL，禁止自动重定向。
